- 修改 `src/antibody_optimization/file_transaction.py`：在任何最终文件变更前，先把全部 staged 文件逐字节复制到各自 `final.parent` 内的唯一安装候选，再执行同目录备份和原子替换。Windows 候选继承目标父目录 ACL；POSIX 候选保留 staged 文件 mode。替换失败时原 stage 始终保留；若 rollback 本身未再次失败，则恢复全部旧目标，不完整 rollback 会显式报错。成功后再清理 stage 和 backup。该路径不复制时间戳、xattr 或显式 ACL，并需要与 staged 数据等量的短期候选空间；当前小型 Git 制品不构成资源问题，预计和实测均远低于 1 小时。
